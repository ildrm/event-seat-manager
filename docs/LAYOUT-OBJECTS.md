# قرارداد اشیای غیرصندلی در نقشه — 1.0.0

قالب JSON با `"format":"pesm.layout.v1"` باقی می‌ماند. آرایه `objects` اختیاری است و نسخه‌های قدیمی با تنها `seats` همچنان قابل ورودند. نمونه:

```json
{
  "format": "pesm.layout.v1",
  "seats": [{"code":"A-1","row_label":"A","number":1,"zone":"عمومی","x":40,"y":70}],
  "objects": [{"id":"STAGE-1","type":"stage","x":0,"y":0,"width":220,"height":45,"label":"سن اصلی"}]
}
```

شیء فقط عنصر بصری است، نه صندلی قابل فروش. مقدار `type` یکی از `stage`, `round_table`, `rect_table`, `aisle`, `door`, `emergency_exit`, `label`, `separator`, `accessible_area` است. `id` در یک نسخه یکتا است و نباید از کد صندلی استفاده شود. مختصات عدد صحیح و ابعاد مثبت‌اند؛ متن با escape و DOM text rendering نمایش داده می‌شود. ورود اطلاعات به جدول اختصاصی `pesm_layout_objects` فقط در تراکنش نسخه پیش‌نویس صورت می‌گیرد.

**محدودیت:** این مدل فعلاً جهت در، شعاع چرخش، استاندارد تخلیه اضطراری، نوع میز، لایه‌بندی و هندسه غیرمستطیلی را ندارد. نمایش راهرو یا خروج اضطراری، تأیید مهندسی ایمنی ساختمان نیست.
