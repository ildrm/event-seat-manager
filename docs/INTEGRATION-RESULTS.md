# آزمون یکپارچه نسخهٔ 1.0.0

این آزمون‌ها در ۴ نوامبر ۲۰۲۶ روی سایت محلی موقت و پایگاه دادهٔ مستقل اجرا
شدند. هیچ درگاه بانکی، ایمیل واقعی یا پیامک واقعی استفاده نشد. شواهد قابل
خواندن ماشین، بدون توکن و اعتبارنامه، در [qa/integration-results.json](qa/integration-results.json)
ثبت شده است.

| مؤلفه | نسخه/وضعیت واقعی آزمون |
| --- | --- |
| WordPress | 7.1.4، نصب واقعی تک‌سایته |
| WooCommerce | 11.2.1، فعال |
| PHP | 8.5.8 |
| پایگاه داده | MariaDB 13.0.2، اتصال socket محلی، تمام ۳۷ جدول افزونه InnoDB |
| طرح افزونه | نسخهٔ داخلی ۱۸؛ مستقل از نسخهٔ محصول 1.0.0 |
| CPT | `WC_Order_Data_Store_CPT` |
| HPOS | `Automattic\WooCommerce\Internal\DataStores\Orders\OrdersTableDataStore`؛ وجود سفارش‌ها در `wp_wc_orders` بررسی شد |
| زبان فارسی | بستهٔ رسمی هستهٔ `fa_IR` نصب شد؛ پاسخ HTTP دارای `lang="fa-IR"` و `dir="rtl"` بود |

اعلان سازگاری WooCommerce پس از افزودن آن نیز در بوت واقعی بررسی شد:
hook `before_woocommerce_init` یک‌بار اجرا شد، `custom_order_tables` در فهرست
سازگار و `cart_checkout_blocks` در فهرست ناسازگار ثبت شدند؛ طرح ۱۸ بدون خطا
و افزونه فعال باقی ماند.

## اجرای دوباره

فقط روی WordPress محلی یک‌بارمصرف با WooCommerce و افزونهٔ فعال اجرا کنید.
`WP_ENVIRONMENT_TYPE` باید `local` باشد. آزمون‌ها دادهٔ فیکسچر می‌سازند و
تنظیمات مالی/ویژگی‌های آزمایشی سایت تست را تغییر می‌دهند؛ آزمون ارتقا دو
جدول خالی بسته‌ها را بازسازی می‌کند.

```sh
PESM_RUN_INTEGRATION=1 wp eval-file /path/to/event-seat-manager/tests/integration-wp.php
python3 tests/integration-concurrency.py /absolute/path/to/wordpress 20

PESM_RUN_INTEGRATION=1 wp eval-file /path/to/event-seat-manager/tests/integration-wp.php representative-storage
PESM_RUN_INTEGRATION=1 wp eval-file /path/to/event-seat-manager/tests/integration-wp.php storage-on
PESM_RUN_INTEGRATION=1 wp eval-file /path/to/event-seat-manager/tests/integration-wp.php representative-storage
PESM_RUN_INTEGRATION=1 wp eval-file /path/to/event-seat-manager/tests/integration-wp.php storage-off
PESM_RUN_INTEGRATION=1 wp eval-file /path/to/event-seat-manager/tests/integration-wp.php retention
```

ابزار Python از فرایندهای PHP جدا و هستهٔ واقعی WordPress استفاده می‌کند؛
این آزمون HTTP یا فشار مرورگر نیست. محیط آزمون اصلی، پس از همگام‌سازی، به
CPT اولیه برگردانده شد.

## حدود این شواهد

این نتایج تأیید درگاه بانکی یا تسویهٔ استرداد، SMTP، ملی‌پیامک، دوربین واقعی،
کارایی زیر بار تولید، نسخه‌های دیگر PHP/WordPress/WooCommerce یا تمام الزامات
پرامپت اصلی نیستند. مالیات و ادغام استاندارد Checkout Blocks کامل نشده‌اند.
نصب و کارکرد مسیرهای آزموده‌شده جایگزین پذیرش امکانات پیاده‌سازی‌نشده مانند
PDF بومی و تسویهٔ اختلاف قیمت انتقال صندلی نمی‌شود.

در اجرای اولیه، دو خطای خود اسکریپت آزمون اصلاح شدند: نام فیلد پاسخ انتقال
و مقایسهٔ سخت‌گیرانهٔ `0.0` با `0`. همچنین WP-CLI 2.12.0 روی PHP 8.5 اخطارهای
deprecated کتابخانهٔ خودش ایجاد می‌کرد؛ اجرای اصلی از driver مستقیم WordPress
استفاده کرد. رد عمدی مبلغ نادرست در لاگ افزونه ثبت شد و خطای کنترل‌نشدهٔ محصول
در اجرای نهایی این سناریوها مشاهده نشد.

## کنترل نصب خود بسته

فایل ZIP با نصب‌کنندهٔ WordPress در نصب تمیز و پایگاه دادهٔ محلی جداگانه نصب شد؛ افزونه از مسیر استخراج‌شده اجرا شد و symlink به مخزن نبود. مجموعهٔ اصلی۵۵بررسی روی آن موفق بود. شواهد بدون اطلاعات حساس در [qa/package-results.json](qa/package-results.json) است.
