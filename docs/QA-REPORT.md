## اصلاحات مهم تأییدشده

- مبلغ، ارز و دقت پولی با snapshot معتبر سفارش و شواهد پرداخت تطبیق داده می‌شوند؛ پرداخت ناقص/دستکاری‌شده بلیت نمی‌گیرد.
- انقضا پس از انتظار قفل با ساعت تازهٔ بانک بررسی می‌شود؛ callback دیررس مالک جدید را کنار نمی‌زند.
- مهاجرت هم‌زمان با قفل advisory بانک سری می‌شود؛ ساختار ناقص مسیر رزرو را فعال نمی‌کند.
- گزارش، رزرو صندلی منقضی را بدون وابستگی به cron آزاد می‌شمارد.
- آدرس REST در پیوند یکتای ساده درست ساخته می‌شود؛ نقشه با صفحه‌کلید فوکوس را حفظ می‌کند و بخش‌های بستهٔ جلسه بارگیری/نظرسنجی بی‌نیاز ندارند.
- پیام‌ها، نقش‌ها، وضعیت‌ها، تاریخ و جهت Excel و رابط در هر دو زبان بررسی شده‌اند.

## حدود پذیرش

PHP ۸.۵.۸،WordPress ۷.۱.۴،WooCommerce ۱۱.۲.۱ و MariaDB ۱۳.۰.۲ آزموده شدند. ماتریس PHP ۸.۱/۸.۳/۸.۵ درCI تعریف شده، اما اجرای GitHub Actions و تمام ترکیب‌های مقصد ادعا نمی‌شود. تست رقابت با PHPworkerهای مستقل است؛ آزمون فشار HTTP/۱۰۰ خریدار یا قطع اجباری worker نیست.

درگاه واقعی، تسویهٔ استرداد،SMTP،ملی‌پیامک، دوربین فیزیکی HTTPS، همهٔ مهاجرت‌های تاریخی، تمام مرورگرها و فناوری‌های کمکی همچنان پذیرش مستقل می‌خواهند. PDF بومی، Checkout Blocks/Store API کامل، خرید تجاری بسته و تسویهٔ اختلاف قیمت هنوز کامل نشده‌اند.

**حکم:** شواهد بالا مسیرهای مشخصی را تأیید می‌کنند؛ تکمیل تمام ۱۱۴ نیازمندی پرامپت و آمادگی کامل فروش عملیاتی تأیید نشده است. [وضعیت انتشار](RELEASE-STATUS.md) مرجع تصمیم است.

جزئیات بازطراحی، کنترل‌های فرم و دسترس‌پذیری و شواهد مرورگر در [UI-UX-REVIEW.md](UI-UX-REVIEW.md) ثبت شده‌اند.
